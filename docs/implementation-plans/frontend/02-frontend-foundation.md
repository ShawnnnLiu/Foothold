# Increment F2: Frontend Foundation

Goal: the `frontend/` scaffold with Ascent design tokens, the typed API layer, and the two React-free `lib/` modules with parity-pinned tests, so every later screen is a thin renderer over already-tested logic.
Binding references: `docs/design/ASCENT.md` (visual spec), `transfer/triage.py` (the view-model being mirrored), `backend/schemas/evaluation.schema.json` (wire truth), `docs/TESTING_STRATEGY.md` and `AGENTS.md` (frontend lib modules are vitest-covered; components have no tests).

New dependencies (user gate at kickoff): runtime `react`, `react-dom`, `@fontsource/archivo`; dev `typescript`, `vite`, `@vitejs/plugin-react`, `vitest`, `@types/react`, `@types/react-dom`.
Scaffold via `npm create vite@latest frontend -- --template react-ts`, then prune to the structure below (delete demo assets, demo CSS, the Vite logo boilerplate).

## Structure (exact)

```
frontend/
  package.json  vite.config.ts  tsconfig.json  index.html
  src/
    main.tsx  App.tsx
    theme/tokens.css
    lib/
      api.ts          # wire types, hand-mirrored from backend/schemas/*.json
      client.ts       # typed fetch wrappers, no logic

      courses.ts      # chip-state transitions
      format.ts       # units/dollar/caption formatting
      __fixtures__/

        board.demo.json        # committed, generated by the same script
    lib/*.test.ts     # vitest, beside the modules
    screens/          # filled by doc 03
    components/       # filled by doc 03
```

- `tsconfig.json`: `strict: true`, `noUncheckedIndexedAccess: true`.
- `vite.config.ts`: dev server proxy `/api` and `/healthz` to `http://127.0.0.1:8000`; vitest config inline (`test: { environment: "node" }`; lib tests need no DOM).
- `package.json` scripts: `dev`, `build` (`tsc -b && vite build`), `test` (`vitest run`), `test:watch`.
- CI: add a `frontend` job to `.github/workflows/ci.yml`: setup-node 22, `npm ci`, `npm run build`, `npm test`.

## `lib/api.ts` (locked)

Hand-written interfaces mirroring the wire JSON with the SAME snake_case field names (no camelCase mapping layer, ever; parity with the backend is field-for-field).
Types: `Evaluation`, `Finding`, `Citation`, `UnitsSummary`, `StudentCourse`, the enums `TriageBucket` and `EvaluationFindingCode` as string-literal unions copied from `docs/specs/reason_codes.schema.md`, plus the doc-01 route shapes `InstitutionRow`, `MajorRow`, `CourseHit`, and `ErrorBody`.
The invariants a consumer may rely on are restated as doc comments: citation non-null for the seven `CODES_REQUIRING_CITATION`, null for `no_articulation`/`unresolved`; `advisement_note` always carries advisements; findings arrive pre-sorted by `sort_findings` and are never re-sorted client-side.

## `lib/evaluation.ts` (locked)

```ts
buildTriageBoard(evaluation: Evaluation): TriageBoard
// TriageBoard = { columns: Record<CreditBucket, Finding[]>, still_owed: Finding[], header: TriageHeader }
// TriageHeader mirrors transfer/triage.py:36 field-for-field.
wallSteps(header: TriageHeader): WallStep[]   // WallStep = { kind: "secure" | "reach" | "owed" }
```

- `buildTriageBoard` is a line-for-line mirror of `build_triage_board` (`transfer/triage.py:58`): pure partition of the pre-sorted findings, no re-sorting, no rounding beyond what the backend already did.
- `wallSteps` is the elevation-chart model, 7 steps total (the prototype's count): with `total = clean + at_risk + still_owed` units, `secure = clean > 0 ? max(1, round(7 * clean / total)) : 0`, `owed = still_owed > 0 ? max(1, round(7 * still_owed / total)) : 0`, `reach = 7 - secure - owed` (floored at 0, and when the subtraction leaves `reach = 0` while `at_risk > 0`, steal one step from the larger of secure/owed).
  The chart is decorative-proportional; the honest numbers live in the caption (`format.ts`), per the honest-count rule.
  `total = 0` returns an empty array and the chart is omitted, never fabricated (`ASCENT.md` elevation chart rule).

## `lib/courses.ts` (locked)

Pure transition functions over `ChipState = { chips: CourseHit[], input: string }`:
`addChip`, `removeChip(code)`, `popChip` (backspace-on-empty-input behavior), `setInput`, `clearInput`, `loadSample`.
Dedupe by `course_code` (add of a duplicate is a no-op that still clears input); order is insertion order; no sorting.
`extractCourseCodes(pasted: string): string[]`: uppercase the text, match the locked pattern `/\b[A-Z]{2,5} ?\d{1,3}[A-Z]{0,2}\b/g`, normalize inner whitespace to one space, dedupe preserving first occurrence.
This regex feeds the deterministic paste path in doc 03 (each candidate is then confirmed against the autocomplete API; nothing enters chips unconfirmed).

## `lib/format.ts` (locked)

`formatUnits(n)` (trailing-zero-free like Python `:g`, so `5` and `4.5`), `formatDollars(n | null)` (`~$1,455` style, `null` -> `null`, callers omit the element), `wallCaption(header)` -> the two lines `"{clean} of {total} units secure"` and `"{at_risk} more within reach"` with exact figures, `citationLabel(citation, majorKey)` -> `"MAJOR AGREEMENT {year_label} - ARTICULATION #{position}"` when `citation.assist_key` contains `/Major/`, else `"DEPT. AGREEMENT {year_label} - ARTICULATION #{position}"`.
Reason-tag copy map from `EvaluationFindingCode` to the six locked tags: `advisement_note` -> `ADVISEMENT NOTE`, `partial_series` -> `PARTIAL SERIES`, `fuzzy_match` -> `FUZZY MATCH`, `stale_year` -> `STALE YEAR`, `double_count_risk` -> `DOUBLE-COUNT RISK`, `unresolved` -> `UNRESOLVED`.

## Parity fixtures (the cross-language pin)

New backend script `backend/scripts/dump_demo_fixtures.py`:

- Runs the committed demo student through `load_bundle` + `build_evaluation` + `build_triage_board` with a FIXED clock (`2026-08-03T00:00:00Z`) and a FIXED id (`eval_` + 16 zeros) so the output is byte-stable.
- Writes `frontend/src/lib/__fixtures__/evaluation.demo.json` (the `Evaluation`) and `board.demo.json` (the board, with `TriageBucket` keys as their string values), both `json.dumps(..., indent=2, sort_keys=True) + "\n"` (the repo's byte-determinism recipe, TR 4.5).
- Has the standard `--check` mode and joins `make schema-check`'s pattern: add `make fixtures-check` invoked by `make check`.

Vitest then pins parity: `buildTriageBoard(evaluation.demo.json)` deep-equals `board.demo.json`.
This single test is the contract that `lib/evaluation.ts` and `transfer/triage.py` never drift.

## Tests (vitest, all in `src/lib/`)

1. `evaluation.test.ts`: the parity deep-equal; purity (same input object twice, deep-equal outputs, input not mutated); order stability (column arrays preserve the findings' incoming order); `wallSteps` pinned for the demo header (expect `secure 5, reach 1, owed 1` from clean 34.0, at risk 5.0, owed 10.0 - executor computes and pins the actual values) and for the zero-total case.
2. `courses.test.ts`: every transition; dedupe; `popChip`; `extractCourseCodes` against a pasted-transcript sample containing the nine demo codes plus noise lines, pinned output order.
3. `format.test.ts`: units/dollars/caption/citation-label cases including `null` dollars and the dept-key branch.

Gates: `npm run build` and `npm test` green; `make check` green (the new fixtures-check included); no dollar or unit literal in `lib/` (everything flows from the fixture or the caller).
